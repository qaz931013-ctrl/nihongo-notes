# 如何新增一篇日文筆記

本專案採用資料驅動設計：**新增課程只要編輯 `data/lessons.json`，不必複製 HTML。** AI 應先閱讀根目錄 `AGENTS.md` 的完整規範。

## 操作步驟
1. 開啟 `data/lessons.json`，確認新主題未重複，選擇唯一英文小寫 `id`。
2. 在陣列最後一筆物件後加逗號，貼上符合下列格式的新物件；最後一筆物件後不要多加逗號。
3. 補齊所有欄位；`quiz.answer` 是從 **0** 開始的正確答案位置。
4. 執行 `python3 -m json.tool data/lessons.json > /dev/null`。
5. 啟動 `python3 -m http.server 8000`，確認首頁自動出現新筆記、搜尋/分類/單字卡/測驗正常。

## 新增內容範本
以下是**範例物件**，需放進現有 JSON 陣列，不要直接取代整份資料：

```json
{
  "id": "shopping-phrases",
  "title": "便利商店購物會話",
  "category": "會話",
  "level": "N5",
  "minutes": 7,
  "summary": "學習在便利商店結帳時常見的簡單日文。",
  "tags": ["購物", "生活會話"],
  "sections": [
    {"heading": "常見的詢問", "body": "店員可能詢問是否需要袋子，先熟悉關鍵單字。"},
    {"heading": "禮貌回應", "body": "不需要時可說「大丈夫です」，但要留意語氣與情境。"}
  ],
  "vocab": [
    {"jp": "袋", "reading": "ふくろ", "zh": "袋子"},
    {"jp": "お願いします", "reading": "おねがいします", "zh": "麻煩您了"}
  ],
  "quiz": {
    "question": "「袋」的讀音是？",
    "options": ["ふくろ", "くつ", "かばん"],
    "answer": 0,
    "explanation": "袋讀作 ふくろ。"
  }
}
```

## 驗收清單
- [ ] 新筆記在首頁出現
- [ ] 搜尋標題或單字能找到
- [ ] 分類按鈕能篩選
- [ ] 點擊筆記可閱讀所有段落
- [ ] 單字卡可翻面
- [ ] 測驗答對與答錯都有回饋
- [ ] 手機版沒有水平捲動
