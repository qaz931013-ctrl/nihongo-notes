# 新增筆記與防重複 SOP
1. 閱讀 `AGENTS.md` 與完整 `data/lessons.json`。
2. 比對現有 ID、標題、文法句型、單字與例句，先產生「新增／合併／跳過」清單。
3. 重複主題優先補充原筆記，不製作近乎相同的頁面。
4. 新筆記維持10～20分鐘，含解說、單字卡、小測驗，所有漢字附正確平假名讀音。
5. 更新 JSON，必要時更新 `assets/app.js` 的讀音對照，驗證 JSON、讀音、ID、題目答案。
6. 上傳 GitHub 後檢查搜尋、分類、筆記、單字卡、測驗與手機版。

## 給 AI 的指令
請先閱讀 AGENTS.md 和完整 lessons.json，逐項比較新講義與現有內容。先告訴我哪些要新增、哪些要合併、哪些因重複而跳過。所有漢字標註平假名，內容設計為每日10～20分鐘，保留原有資料與網站風格，最後提供驗證過的完整 JSON。
